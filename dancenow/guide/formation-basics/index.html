ダンスの構成(フォーメーション)の作り方 — 基本の手順

ショーケースや発表会の構成を、ゼロから組んでメンバーに渡すまでの流れ。

構成は「どこに立つか」だけでなく、「いつ・何カウントで・どこを通って動くか」まで決めて初めて、メンバーが同じ絵を頭に持てます。ここでは、振付がある程度できている前提で、構成を組む順番を7つの手順にまとめます。

1. 先に決めておくこと

  • 人数。出る人と、場面によって袖で待つ人。
  • ステージの広さ。会場の間口と奥行き、センターから左右に何番までバミリを貼るか。分からなければ、会場の図面かスタッフに聞いておく。
  • 持ち時間。イベントの枠に収まる長さか。
  • 入りとハケ。幕が開いた時にもう立っているのか、上手・下手の袖から出てくるのか。

2. 音源を先に固める

構成は音に乗せて動くので、音源が変わると移動のカウントが全部ずれます。曲のカット、つなぎ、フェードを先に決めて、「これが本番の音」という1本を作ってから構成に入ります。

音源が決まったら、曲ごとに1カウント目(どこから「1」と数えるか)とテンポを確かめます。イントロの途中から数えるのか、頭から数えるのか、ここでメンバーと食い違うと練習のたびに混乱します。

3. エイトで区切って、場面に分ける

音源をエイト(8カウント)で数え、構成が変わる区切りを書き出します。たとえば「イントロ 2エイト → ファスユニ 4エイト → パート振り① 4エイト → …」のように、場面の名前と長さ(何エイトか)の一覧にします。

名前は現場で口に出して通じるものにします。「サビ前」「ファスユニ」「パート振り②」のように、練習で「◯◯の頭から」と言える名前だと、そのまま稽古の段取りに使えます。

4. 立ち位置をバミリで決める

場面ごとに、全員の立ち位置を決めます。位置はバミリの番号で呼ぶと、紙でも口頭でもずれません。

  • 左右はセンター(0)から上手・下手に1、2、3…。上手は客席から見て右、下手は客席から見て左。
  • 前後は列で呼ぶ(いちばん客席側を1列目、など)。チームで呼び方を1つに揃えておく。
  • 目盛りと目盛りの間に立つ時は、外足・内足で言い分ける。「上手3に外足」なら、センターから遠い方の足を3のバミリに乗せる。

客席から見た図で描くか、踊る側から見た図で描くかは、最初に決めて統一します。上手・下手で呼んでいれば、図の向きが変わっても言葉はずれません。

5. 移動を決める

場面と場面の間の動きを決めます。決めることは3つです。

  1. 何カウントで動くか。「4カウントで移動して、残り4カウントでキメ」のように、移動の長さと、着いてからの長さを分ける。
  2. どこを通るか(動線)。すれ違う2人がぶつからないか、前の人の間を抜けるのか、外を回るのか。
  3. ハケ・入り。袖に入る人はどちらの袖へ入り、次にどちらの袖から出てくるか。

全員を同じカウントで動かそうとすると、通り道が重なって渋滞しがちです。列ごと・グループごとにカウントをずらすと、見た目にも流れが出ます。

6. 書き起こしてメンバーに配る

場面ごとの立ち位置を、1枚ずつの図にします。図には名前(または番号)・バミリ・移動のカウントを入れ、場面の順に並べます。

紙の図だけだと「いつ動き出すか」が伝わりにくいので、音と合わせて動きが見える形(音源つきの動画など)で渡すと、メンバーが自主練で確かめやすくなります。

7. 本番の広さで通して確かめる

稽古場に本番と同じ間隔でバミリを貼り、音源を流して通します。見るのは次の点です。

  • 移動がカウント内に終わるか(終わらない所は、カウントを増やすか動線を短くする)。
  • すれ違いでぶつかる所がないか。
  • 客席の端から見て、後ろの人が前の人に隠れていないか。

直した所は、図と配ったものも必ず直します。古い版が残っていると、本番直前に「どっちが正しいの?」が起きます。

この手順をアプリでやるなら

iPhone アプリ「DanceNow」では、この流れを1台で進められます。音源を切ってつなぎ、曲ごとにテンポと1カウント目をタップで決め、場面をスライドとして並べて、バミリと上手・下手で立ち位置を置き、移動のカウントと袖へのハケまで書けます。できた構成は音つきの動画にしてメンバーに送れます(受け取る側にアプリは要りません)。動画も音源も端末の外に出ません。App Store で見る
